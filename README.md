### Features
- **Interactive Scatter Plot:** Explore relationships between the hour of day, heat index levels, and ignition causes.
- **Dynamic Filtering:** Toggle categories on/off instantly via the custom legend.
- **Axis Switching:** Swap X and Y axes dynamically to analyze temporal vs. thermal patterns.
